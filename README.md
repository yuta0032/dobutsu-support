# どうぶつ がったい — サポート／プライバシーポリシー

iOS アプリ「どうぶつ がったい」（CHERRY BLOSSOM）の公開ページ。

- https://yuta0032.github.io/dobutsu-support/ — 入口（アプリの説明・保護者の方へ）
- https://yuta0032.github.io/dobutsu-support/privacy.html — プライバシーポリシー

App Store Connect の `privacyPolicyUrl` と `supportUrl` に入れる。

書き方の決まり
- 「無料」「お試し」「体験版」の語を書かない（App Store 2.3.7）。
- 対象は 4〜9 歳。子ども向けアプリなので、広告は非パーソナライズ・ATT なし。
- 購入・復元・外部リンクは保護者ゲートの後、と明記する。
